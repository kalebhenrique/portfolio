## Visão Geral

Este projeto foi desenvolvido durante a minha capacitação e período de trainee na **Empresa Júnior Struct**, da Universidade de Brasília. O objetivo foi aprofundar conhecimentos práticos em desenvolvimento backend, arquitetura MVC e boas práticas com o ecossistema Ruby on Rails.

## Principais Funcionalidades

- **Arquitetura RESTful**: Endpoints estruturados seguindo convenções do Rails para operações CRUD com serialização JSON otimizada.
- **Autenticação e Autorização**: Mecanismos de controle de acesso para rotas protegidas.
- **Modelagem de Dados**: Migrations relacionais com PostgreSQL, validações de integridade no ActiveRecord e testes automatizados.
- **Tratamento de Erros**: Respostas HTTP semânticas e consistentes para requisições de clientes web e mobile.

## Aprendizados e Tecnologias

A experiência foi essencial para consolidar a mentalidade de engenharia de software ágil, trabalho em equipe e entrega contínua dentro da empresa júnior.
